# 实验报告模板格式（仰恩大学 · 路由与交换技术）

## 表格结构

`doc.tables[0]` 为 8 行 4 列：

| 行 | 内容 |
|---|---|
| r0 | 标题「路由与交换技术实验报告」（整行合并） |
| r1 | 班 级 / 学 号 / 姓 名 / 报告日期（标签） |
| r2 | 班级 / 学号 / 姓名 / 报告日期（由 `report.json` 的 `student`、`date` 写入） |
| r3 | 实验题目 + 题目（合并） |
| r4 | 实验步骤及结果 + 正文（合并，cells[1..3] 是同一个 tc） |
| r5 | 实验总结 + 正文（合并） |
| r6 | 教师评语 |
| r7 | 成绩 |

## 排版参数

| 元素 | 字体 | 字号 | 段落 |
|---|---|---|---|
| 一级标题 | 黑体 加粗 | 11 pt（`sz=22`） | 段前 6 pt、段后 3 pt |
| 步骤/二级标题 | 黑体 加粗 | 10.5 pt（`sz=21`） | 段前 4 pt、段后 2 pt、行距 269 |
| 正文 | 仿宋 | 10.5 pt（`sz=21`） | 段后 3 pt、行距 274 |
| 命令块 | Consolas | 8.5 pt（`sz=17`） | 左缩进 7.1 pt（`w:ind left=142`）、段前 2 pt、段后 5 pt |
| 图注 | 仿宋 | 9 pt（`sz=18`） | 居中、段后 7 pt |
| 图片段落 | — | — | 居中、段前 4 pt、段后 2 pt |

## 图片宽度

- 交换机/命令回显截图：4.13 in
- 拓扑图：3.4–3.6 in；原图分辨率低可放到 4.13 in
- 竖长的多组 ping 截图：3.0 in
- 宽而矮的 ping 截图（宽高比 > 1.5）：3.5–3.8 in
- 经验值：宽度（in）≈ 像素宽 / 150，且不超过 4.13 in，保证文字清晰

## 图注写法

`图 N␣␣说明`，图与编号之间两个空格；说明包含设备、命令和结论，例如：

`图 3  fjh_sw2 的 display stp brief：GE0/0/1 为根端口，GE0/0/2 为指定端口`

## 常见排版问题

- **最后只剩「成绩」一行单独一页**：把 r4 的 `trHeight` 从 5076 改为 630（`hRule=atLeast`），正文内容长时不影响外观。
- **图注和图片被拆到两页**：把图片段落设为「与下段同页」（`keep_with_next`），或略微调小图宽。
- **截图看不清**：先看原图像素；`px / 150` 小于当前宽度说明被放大了，应缩小图宽或重新截图。
- **命令块换行错乱**：一个段落内用 `<w:br/>` 分行，不要拆成多个段落。
- **表格跨页断行难看**：正文单元格允许跨页；不要给 r4 设固定行高（`hRule=exact`）。

## 内容组织

推荐结构与指导书保持一致：

```text
一、实验目的
二、实验环境与拓扑
三、实验步骤及结果
  （一）<模块名>
    实验需求（摘自实验文件）
    1、<文件中的第 1 步>
       命令块 + 说明
       图 + 图注
    ...
  （二）<模块名>（待补充）
四、实验结果
实验总结
```

「实验需求」照抄指导书；「结果分析」写因果（为什么通/不通、时延为什么变化），不要只罗列现象。

## report.json 示例

```json
{
  "template": "C:/Users/.../112320250050傅俊豪实验二.VLAN综合实验.docx",
  "out": "C:/Users/.../112320250050傅俊豪实验三.STP与MSTP.docx",
  "date": "2026.10.19",
  "title": "STP 与 MSTP 配置",
  "summary": "本次实验……",
  "row4_min_twips": 630,
  "blocks": [
    {"type": "h1", "text": "一、实验目的"},
    {"type": "body", "text": "1．理解 STP 的作用与工作原理……"},
    {"type": "cmd", "lines": ["[fjh_sw1]stp mode stp", "[fjh_sw1]display stp brief"]},
    {"type": "img", "path": "C:/Users/.../实验三-STP拓扑.png", "width": 3.6},
    {"type": "cap", "text": "图 1  STP 部分的实验拓扑"}
  ]
}
```

`img.width` 单位是英寸；`row4_min_twips` 可省略（保留模板原值）。

块类型：`h1`（章标题，11 pt）、`head`（节/步骤标题，10.5 pt）、`body`、`cmd`、`img`、`cap`。

## 空白模板与同学使用

`assets/实验报告模板.docx` 是去掉个人信息的空白模板：表头为空、正文为空，可直接作为 `report.json` 的 `template` 使用。

```json
"student": {"class": "网络工程1班", "id": "你的学号", "name": "你的姓名"},
"date": "2026.10.26"
```

`student` 会写入表格第 2 行的班级/学号/姓名，`date` 写入报告日期。
模板正文为空时，`build_report.py` 会用内置样式常量（与上表一致）生成段落，不需要手动准备示例段落。
