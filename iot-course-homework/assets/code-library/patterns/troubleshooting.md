# 课件代码常见问题

## 必须修正的课件笔误

1. 第4次 OLED 字符串使用了弯引号 `“123456"`，C++ 中必须改成直引号。
2. 第5次例2写成 `Loop()`，正确入口是 `void loop()`。
3. 第5次第14页 `delay(200)` 按截图保留，但红灯步骤通常是秒级延时，应结合实验要求确认。
4. 第6次综合代码同时把 `BUZZER` 和 RGB 数据脚设为 `A0`。
5. 第6次例3只打印 `"Duty: "`，没有打印 `duty` 数值。
6. 第9次 `Read_ADXL345()` 直接复制时，必须同时声明 `ADXL_Data`、`iX/iY/iZ` 和 `sX/sY/sZ`。
7. 第10次函数名是 `MoterMove`，不是 `MotorMove`。
8. 第18次 RFID 截图中 UID 字符串拼接存在重复赋值，使用库中整理版。
9. 第19次 `pulseIn()` 没有超时参数，远距离无回波时应增加超时和有效值判断。
10. 第20次 `IRremote` 使用旧版 API，安装新版库时可能无法直接编译。

## 常见编译问题

- `No such file or directory`：缺少课程私有库或第三方库。
- `multiple definition of setup/loop`：把多个完整示例直接粘贴到了同一文件。
- `Servo.h` 与部分 PWM 引脚组合冲突：换脚或改用软件舵机库。
- `FastLED` 未安装：库管理器安装 `FastLED`。
- `DHT12.h` 与 `DHT.h` 混用：对象类型和 API 不一致。

## 硬件检查

- 模块供电电压要与课程板匹配。
- 电机必须经过驱动模块，不能直接由 GPIO 供电。
- 舵机和电机动作时 OLED 复位，通常是供电或共地问题。
- `A3` 等模拟脚被多个模块复用时，不能只改代码而不改接线。
