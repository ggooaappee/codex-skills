## 必须检查的引脚冲突

1. `A3` 在不同课程中分别用于蜂鸣器、DS18B20、DHT12、光照、麦克风、雨滴和红外接收。一个程序不能同时让多个互斥模块占用同一实际引脚。
2. RGB 使用 `A0`，而第6次综合代码又写 `#define BUZZER A0`。应按第3次接线页把蜂鸣器改回 `A3`，或按实际硬件重新分配。
3. 直流电机和舵机 1 都使用 `D10`，不能在没有换脚或分时供电的情况下同时控制。
4. 舵机 2 使用 `D11`，RFID 的 MOSI 也使用 `D11`，组合时要重新分配或确认硬件总线复用方式。
5. 步进电机使用 `D9-D12`，会与舵机、直流电机和 RFID 的部分引脚重叠。
6. 摄像头式模拟模块的装配页有时写“A0、A3”，但程序中实际引脚以对应模块代码页为准。
